# payday-legal

Public legal pages for the Payday budgeting app, hosted with GitHub Pages.

## Pages

- Privacy policy: https://justinjmcklean.github.io/payday-legal/privacy/

## How it works

- `privacy/index.html` is a single static page. Plain HTML and CSS only.
- No scripts, no trackers, no external fonts or requests.
- GitHub Pages serves the `main` branch from the repo root.

## Updating

Edit `privacy/index.html`, update the effective date, and push to `main`. The site refreshes in about a minute.

## Not here

This repo holds only the legal pages. It contains no app code, keys, or data.
